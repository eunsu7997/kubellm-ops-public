# 공개본 점검과 원본 보존

이 저장소는 사용자 승인으로 비공개 원본에서 선별한 공개본입니다. 과거 Git 이력·작성자 개인 이메일·원시 archive·스크린샷·실제 tailnet 주소·계정은 복사하지 않았습니다. 최초 공개 커밋은 GitHub noreply 이메일을 사용합니다.

실측 증거는 선별·부분 비식별한 파생본이며 original/export SHA256을 구분합니다. 원본은 집 PC와 비공개 저장소에서 보존하고 삭제·rewrite·force push하지 않았습니다. 기존 로그를 비식별한 결과를 원본이라고 소개하지 않습니다.

개인키·일반 API token·개인 이메일·실제 개인 tailnet 식별자 패턴을 검사하고 export hash를 대조합니다. 기존 스크린샷14개와 ZIP 내부134개 파일도 원본에서 제한적으로 검토했지만 공개본에는 포함하지 않았습니다. 임의 인코딩 비밀값이나 모든 외부 시스템을 포괄하는 보안 인증은 아닙니다.

GitHub 공개본은 전체 과거 실험의 raw archive mirror가 아닙니다. 아래 역사 문서는 선택한 참고 자료이며 일부 세부 원본은 비공개 보존 대상입니다. 공개 범위 밖 자료를 접근 가능한 공개 증거라고 주장하지 않습니다. 최신 결과는 PORTFOLIO-20261023.md와 public-integration-20261023 자료를 우선합니다.
